This repository contains two versions of a simulation of American Elections based on ANES data from 1972-2020. 

The older version, located in the folder '2024_anes_model', is a predictive model of historical election outcomes that functions by first computing vote probabilities in the national ANES file. Then, in order to compute vote shares in the states, the model subsequently reweighting each observation to states according to time-series Census data. The code required to test various combinations of weighting variables is included in 'test_regression.py', although beware -- the code is quite messy.

The second version of the simulation, which is contained within the folder '2026_ordinal_ideology_model', is a model that differs from the first in that the weights used to compute state vote shares are based on the estimated ideological distribution of respondents in each state. I have used the ANES data to compute the probabilities that a selected voter in a given state and year identifies at each point on the seven-point ANES ideology and 'Aid to Blacks' scales, and predict vote probabilities along each position on the two scales, weighting by the frequency of voters at each position in each state. I have yet to assess how the model weighted according to ideology predicts historical elections with the aformentioned python file, so this an avenue for future exploration.
